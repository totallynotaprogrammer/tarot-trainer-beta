# Tarot Trainer · Android Beta

Public APK distribution for **Miami Esoterica Tarot Trainer**. The source code remains in a separate private repository.

## Install or update

Download **Tarot-Trainer-Android.apk** from the [latest release](../../releases/latest). Open the file on an Android device and follow the installation prompts. Android may require permission to install from your browser or file manager.

Updates must use the same signing certificate and increasing Android version codes to install over earlier versions. Notes are stored locally, so back up anything important.

## Beta testing permission

Miami Esoterica permits downloading, installing, and evaluating the APK for personal, noncommercial beta testing. No permission to modify, redistribute, or commercially exploit the application is granted. This is not a source-code license. The historical Rider-Waite-Smith artwork remains public domain.

Beta builds may contain defects. Check the release's SHA-256 checksum when verifying a download.
